# kuangrad write-up

A static, scroll-driven walkthrough of the engine. The article is on the right. On the left, the computation graph
gets a yellow box around the part being discussed, and each passage's code slides into a stack below it.

- `content.js`: every passage, its card, and the graph region it highlights
- `graph.js`: the computation graph (nodes, weight matrices, yellow highlight boxes) and the forward/backward animation
- `cards.js`: code listings and the visual cards (digits, edge, Jacobian, BFS, cost)
- `format.js`: prose formatting shared by everything: `code`, **bold**, `$tex$` / `$$tex$$` through KaTeX, and the word
  Neuron set as code
- `app.js`: scroll tracking, the card stack, the details dialog, Contents, the arrow keys
- `split.js`: the draggable line between the two panels, shared with the Results tab
- `snippets.js`: generated, do not edit
- `pass.js`: generated by `scripts/build_pass.py` (one real step, the numbers the graph shows), do not edit
- `results.html`, `results.js`, `results.css`: the Results tab, a drawing pad running the trained network and the
  training run's loss curve
- `infer.js`: `inference.py`'s forward pass in JavaScript, for the Results tab, plus `frame()`, which crops, scales and
  centres the pad's drawing the way the training drawings sit
- `results/`: generated, do not edit. `model.bin` is every weight and bias as float32, `run.js` the loss at every step
- `vendor/katex/`: KaTeX 0.16.22 (MIT), woff2 fonts only

Preview locally:

```sh
python3 -m http.server -d writeup 8000   # then open http://localhost:8000
```

Code cards are copied from the repo's `.py` files by line range. After editing a `.py` file or a card's `ranges`,
regenerate them (CI-style check: add `--check`):

```sh
node writeup/scripts/build-snippets.mjs
```

The Results tab is built from `model.json` and `train_log.txt` (both gitignored). After a training run, or on a
checkpoint mid-run with `--iterations` set to the step it was saved at:

```sh
node writeup/scripts/build-results.mjs
```

The site at kuant.space copies this folder from `main` at build time (`scripts/sync-projects.mjs` in the portfolio
repo), the same way it serves `/pi/` and `/genie/`.
